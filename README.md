# 🖥️ Screen Translator

**Screen Translator** is a powerful, real-time subtitle translation tool that captures your screen and translates on-screen text instantly — perfect for gamers, language learners, and streamers.

---

## 🚀 Features

- Translate any subtitle or text that appears on your screen
- Real-time translation with customizable subtitle display
- Multi-language support (English, Turkish, and more)
- Lightweight and fast

---

## 📦 Installation

### Windows

1. [Download latest release](https://github.com/rasnet0001/screen-translator)
2. Extract and run `ScreenTranslator.exe`
